# Dimension artwork

Generated with the built-in image tool from the user-supplied End, Nether, zombified piglin, and Trial Chamber references. Generated interpretations, not pixel-exact texture copies. WebP packaging preserves image dimensions. Full-resolution PNGs are retained under `output/imagegen/dimensions/`.

The obsidian frame generator returned an opaque checkerboard despite an alpha request. PortalFrame uses an explicit CSS ring clip to exclude the background and opening, with a separate live animated purple surface. Do not display the raw frame unmasked.
