# End artwork (application portal background)

Mohak's painting of End islands, taken from the single raster embedded in the artwork PDF at native resolution (1323 x 764) with `pdfimages -all`, then encoded by `scripts/package-end-portal-art.py`. Not redrawn or recoloured.

- `end-sky-wide.webp`: the whole painting, for landscape screens.
- `end-sky-tall.webp`: a 600 x 764 portrait crop centred on the big middle island, for phones.
